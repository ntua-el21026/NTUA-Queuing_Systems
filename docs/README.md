# Documentation

This folder contains supporting material for the NTUA Queuing Systems coursework.

## Contents

- `lectures/`: course lecture PDFs covering queueing-system foundations, Poisson and exponential distributions, Markov birth-death processes, M/M/1 and finite queues, simulation, multi-server systems, queueing networks, and forecasting methods.
- `project_structure/`: a small helper script and a generated text snapshot of the repository tree.

## Organization

The lecture files are kept as reference material for the lab reports and implementations. The project-structure files document the repository layout and are useful when checking whether each lab has the expected `assignment/`, `programs/`, `report/`, and `submission/` folders.

The lab-specific explanations, implementation notes, and run commands are documented in the README files under `labs/1st/` through `labs/5th/`.
